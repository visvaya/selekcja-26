# Security policy

## Supported version

Only the current `main` branch and the deployed game built from it are supported.

## Scope

Selekcja 26 is a static browser game with no backend, no accounts and no analytics. Game progress is stored only in the player's own browser (`localStorage`). Relevant reports include, for example, script injection through a crafted save, weaknesses in the response headers, or a vulnerable dependency that reaches the shipped bundle.

## Reporting a vulnerability

Please report privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for a security problem.

A first reply can be expected within 7 days. This is a hobby project maintained by one person, so fixes are made on a best-effort basis.
